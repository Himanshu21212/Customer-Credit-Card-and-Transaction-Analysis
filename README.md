# credit-card-data-analysis

**About**

Analyzed 100K+ credit card transactions using **SQL & Power BI** to identify revenue trends, customer segments, and key profitability drivers.

**Steps I Followed**

* Created a relational SQL database with two tables (`cc_detail` for transactions and `cust_detail` for customer data)
* Loaded and organized 100K+ records, ensuring proper joins and analysis-ready datasets
* Developed interactive Power BI dashboards with filters for card type, age, education, income, job, and expenditure type
* Analyzed revenue, transaction volume, interest earned, and customer demographics

**Results & Insights**

* Overall KPIs: **57M revenue, 7.98M interest earned, 667K transactions**
* **Blue cards** led performance with **47M revenue and 6.6M interest**
* Customers aged **30–40 years** generated the highest revenue (**14M**)
* **Graduates** contributed the highest revenue (**13M**) among education levels
* **Businessmen** were the top contributors by occupation (**9M**), while self-employed and retirees contributed approximately **5M each**
* **Bills (14M+)** and **Entertainment (~10M)** were the leading expenditure types
