# credit-card-data-analysis

**About**

Analyzed 100K+ credit card transactions using SQL & Power BI to uncover revenue patterns, customer segments, and profitability drivers.

**Steps I Followed**

Designed a relational SQL database with two tables (cc_detail for transactions, cust_detail for customers)

Loaded and structured 100K+ records, ensuring clean joins and analysis-ready datasets

Built interactive Power BI dashboards with filters for card type, age, education, income, job, and expenditure type

Visualized revenue, transactions, interest, and customer demographics


**Results & Insights**

Overall KPIs: 57M revenue, 7.98M interest earned, 667K transactions

Blue cards dominated with 47M revenue and 6.6M interest

Customers aged 30–40 yrs generated the highest revenue (14M)

Graduates contributed the most revenue (13M) among education levels

By occupation, Businessmen (9M) were top contributors, with self-employed and retirees (~5M each) also significant

Bills (14M+) and Entertainment (~10M) were the top expenditure types
